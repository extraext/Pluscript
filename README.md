## Pluscript - An advanced coding software

The app includes the following features and architecture:

### 1. **Workspace & File Management**
- Multi-file tab bar supporting quick tab switching, closing, unsaved edit indicators, and file creation.
- Slide-over file drawer with file creation, renaming, deletion, reloading, and file count stats.
- File Import/Export: support uploading files across all common extensions while keeping native extensions intact.
---
### 2. **Editor Canvas & Performance**
- Seamless text editing with syntax highlighting for 20+ programming, scripting, and markup languages.
- Viewport optimization ensuring zero lag even on massive files over 1,000+ lines.
- Formatting guides: dynamic indent detection, gutter change markers, and block scope highlighting.
- Mobile accessory bar with quick-insert symbols, undo/redo, block indentation, and navigation keys.
- Status bar showing line/column numbers, total line count, and a fast language switcher.
---
### 3. Search & Replace System
- Full search bar with match counters, regex support, and case-sensitive toggles.
- Quick navigation controls to cycle through and visually highlight matches.
- Single replace and Replace All operations.
---
### 4. Execution Engines & Previewers
- JavaScript/TypeScript Engine: execute code client-side with captured console logs and execution metrics.
- Python Engine: built-in WebAssembly runtime supporting Python scripts and image generation libraries.
- Image Output: view and download images generated by scripts directly within the environment.
- Integrated Previewers: live sandboxed rendering for HTML, token inspection for XML, and a full markdown renderer.
---
### 5. Themes and User Preferences
- Multiple dark and light themes (Dark Slate, Light, Vivid Dark, Monokai, Nord,).
- Customization menu to adjust font sizes, word wrap, auto-save, and color schemes.
