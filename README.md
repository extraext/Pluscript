## Pluscript: An advanced coding software and IDE
Edit, run, and commit code from your GitHub repositories on virtually any device. 

1. ### GitHub Integration
- Connect your GitHub account and browse any public or private repo you have. 
- You'll see the source code files of your repo after selecting one, in which you can commit changes to directly from the app, along with editing the commit message as well. 
- more... 

---

2. ### **Workspace & File Management**
- Multi-file tab bar supporting quick tab switching, closing, unsaved edit indicators, and file creation.
- Slide-over file drawer with file creation, renaming, deletion, reloading, and file count stats.
- File Import/Export: support uploading files across all common extensions. 

---

3. ### Editor
- Syntax highlighting for many languages (and supports custom ones). 
- Handles large files without lag.
- Indent guides and change markers. 
- more... 

---

4. ### Searching
- Regex and case-sensitive search with live match highlighting. 
- Replace one occurrence or all at once. 

---

5. ### Code Execution
- JavaScript/TypeScript execution with full console output. 
- Python via an in-browser runtime working fully offline, including image generation. 
- Live previews for HTML, XML, and Markdown. 

---

6. ### Universal Integration
- Accessory bar for quick symbols, undo/redo, and indentation made for integration in almost any device with a proper OS. 
- Multiple dark themes and a light theme.
- Integrated toggleable options like Line Wrap, Smart Indent, and more.
- Adjustable font size.
